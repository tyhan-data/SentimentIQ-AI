# SentimentIQ-AI

A sophisticated sentiment analysis system that predicts and classifies emotional context from text data with high accuracy.

## Overview

SentimentIQ-AI is a comprehensive sentiment analysis application that leverages machine learning to understand and predict the sentiment of input text. Whether positive, negative, or neutral, the system provides intelligent sentiment classification for various applications.

## Features

- **Real-time Sentiment Analysis**: Instant classification of text sentiment
- **High-Accuracy Predictions**: Advanced machine learning models trained on diverse datasets
- **User-Friendly Interface**: Streamlit-based web application for easy interaction
- **Multiple Sentiment Classifications**: Support for positive, negative, and neutral sentiment detection

## Technology Stack

- **Python**: 13.6% - Core backend logic and model implementation
- **Jupyter Notebook**: 86.4% - Model development, training, and experimentation

## Installation

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/tyhan-data/SentimentIQ-AI.git

# Navigate to the directory
cd SentimentIQ-AI

# Install required dependencies
pip install -r requirements.txt

# Run the Streamlit application
streamlit run app.py
```

## Usage

1. Navigate to the web application
2. Enter the text you want to analyze
3. Click the analyze button
4. View the sentiment prediction and confidence score
